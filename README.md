# LOCO PREDICT (демо, без входа)
Один файл `index.html` + `css/ui.css` + Firestore. Роли «Заказчик/Депо» — переключатель в шапке (демо, не защита).
QR ведёт на `/?loco=ID`.

## Что есть
- Паспорт: все узлы локомотива добавляются автоматически (по типу: электровоз / тепловоз), у каждого — состояние,
  вид/дата/пробег последнего обслуживания (ТО-1…ТО-8, ремонт, осмотр), примечание и история изменений.
- «Где поломка» — выбор узлов кнопками (в анкете приёмки и в паспорте у депо).
- Фото: в анкете и в паспорте, привязка к узлу. Хранятся в Firestore (сжатие до ~0,8 МБ), Storage не нужен.
- Удаление паспорта (с подтверждением номером) — каскадно: ремонты, задачи, история, узлы, ИИ-анализы, фото.
- 18 стадий ремонта (дефектовка, разборка, сборка, регулировка, испытания, мойка и окраска и др.) + «ожидает детали», «приостановлен».
- Свои диалоги, выпадающие списки и календарь вместо стандартных prompt/confirm/select/date браузера.
- ИИ: Groq, бесплатная модель llama-3.3-70b-versatile (выбор модели убран).

## Ключ ИИ
Хранится в Firestore: коллекция `settings`, документ `ai`, поле `key`. Роль «Депо» → кнопка «ИИ-ключ» → вставить ключ.
Ключ в код не записан. Он читается клиентом, поэтому виден любому посетителю — для продакшена нужен Cloud Function-прокси.

## Деплой
`firebase deploy --only firestore:rules,hosting` (правила обновлены: добавлены `photos` и `settings`).
